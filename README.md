# Shreetek Website

A modern, professional corporate website for Shreetek, built with Next.js 16, Tailwind CSS, and Framer Motion.

## 🚀 Features

- **Modern UI/UX**: Responsive design with smooth animations using Framer Motion.
- **Dynamic Pages**: Dedicated sections for About, Careers, Industries, Recruitment, and Software services.
- **Contact Integration**: Integrated contact and resume submission forms via API routes.
- **Optimized Performance**: Built with Next.js App Router for fast loading and SEO optimization.

## 🛠️ Tech Stack

- **Framework**: [Next.js 16](https://nextjs.org/)
- **Styling**: [Tailwind CSS 4](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Email**: Nodemailer for form submissions

## 📦 Installation & Local Development

1. **Clone the repository:**
   ```bash
   git clone https://github.com/YOUR_USERNAME/shreetek-web.git
   cd shreetek-web
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🌐 Deployment

This project is configured for deployment on **Vercel**. 

1. Push your code to GitHub.
2. Import the repository into Vercel.
3. Configure environment variables for SMTP (email) settings.
4. Deploy!

## 📁 Project Structure

- `src/app/`: Application routes and pages.
- `src/components/`: Reusable UI components.
- `src/lib/`: Utility functions and email templates.
- `public/`: Static assets.
